# Combat Bots — مود بوتات القتال والبناء (Fabric، ماين كرافت جافا 1.21.1)

بوتات بشكل لاعب (لها سكن) تقاتل الوحوش، تهاجم اللاعبين، تدافع عنك، وتبني منزلًا.

## الحصول على ملف المود (.jar) بدون تثبيت أي شيء

1. أنشئ مستودعًا جديدًا على GitHub وارفع كل محتويات هذا المجلد إليه.
2. افتح تبويب **Actions** ← سيعمل البناء تلقائيًا (أو اضغط *Run workflow*).
3. بعد دقيقتين تقريبًا افتح التشغيل المكتمل ونزّل الملف من **Artifacts** (`combat-bots-mod`).
4. فك الضغط، وستجد `combat-bots-1.0.0.jar`.

(بديل محلي: ثبّت JDK 21 و Gradle 8.10 ثم نفّذ `gradle build` وستجد الملف في `build/libs/`.)

## التثبيت في اللعبة

1. ثبّت **Fabric Loader** لنسخة **1.21.1** (https://fabricmc.net/use/).
2. ضع **Fabric API** لنسخة 1.21.1 في مجلد `mods` (https://modrinth.com/mod/fabric-api).
3. ضع `combat-bots-1.0.0.jar` في نفس المجلد `mods`.
4. شغّل اللعبة بملف تعريف Fabric.

## الاستخدام (يلزم تفعيل الأوامر / Cheats)

| الأمر | الوظيفة |
|---|---|
| `/bot spawn <اسم> [سكن]` | إنشاء بوت. السكنات: `knight` `warrior` `ninja` `builder` `robot` |
| `/bot mode <اسم\|all> guard` | يدافع عنك ويهاجم الوحوش (الافتراضي) |
| `/bot mode <اسم\|all> hunt` | يهاجم الوحوش واللاعبين (عدا صاحبه) |
| `/bot mode <اسم\|all> build` | يبني منزلًا خشبيًا 5×5 أمامه |
| `/bot mode <اسم\|all> idle` | يتوقف عن القتال والبناء |
| `/bot team <اسم\|all> <رقم>` | فريق؛ البوتات من فرق مختلفة تقاتل بعضها |
| `/bot remove <اسم\|all>` | حذف بوت |
| `/bot list` | عرض البوتات |

كما توجد **بيضة إنشاء** (Bot Spawn Egg) في تبويب بيض الإنشاء بالوضع الإبداعي.

## سكن مخصص

ضع صورة سكن بحجم 64×64 باسم `myskin.png` في
`src/main/resources/assets/botmod/textures/entity/` وأعد البناء، ثم:
`/bot spawn Ahmed myskin`

لتغيير السكنات الجاهزة عدّل `tools/make_skins.py`.
